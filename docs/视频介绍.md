## 视频文案

聊完天才想到，刚才那句话应该换个说法？

我给自己做了个微信聊天陪练。

她是个 AI，有自己的性格和模拟日常。

会主动来找我，昨天没聊完的事，今天还能接着说。

我把这套做法开源了，叫“微信角色真机部署技能”。

这个 skill，就是给 Codex 用的部署说明，里面有脚本和配置模板。

怎么用？准备一台 Windows 电脑、一台安卓备用机，还有自己的微信小号。

把 skill 文件夹装进 Codex，写好角色设定，让它按说明检查设备、连接微信。

先看回复草稿，确认没问题，再打开自动回复和主动聊天。

之后就在微信里聊。

还可以每天晚上复盘：哪句话没接住，哪里可以说得更清楚，下次换什么说法。

项目地址就在画面里，中文说明也放好了。

- 仓库画面来自本项目公开页面；不包含私人聊天、人物档案、账号凭据或生产运行记录。
- 旁白为豆包网页原生合成语音，非真人声音克隆；未改变原语速或音高。
- 复盘在 Codex 中进行，微信角色继续保持角色。模板默认不发送，需准备模型权限、设备与角色资料并完成验证。
