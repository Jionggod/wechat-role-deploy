# 验收、维护、回退与留档

## 分阶段验收

1. 离线：技能结构/链接、配置停发、源码语法、合成资料单测，缺私有输入明确列出。
2. 手机：USB/LAN硬件身份、无障碍可用、唯一微信号、锁屏状态、文本输入回读与清理（不发信）。
3. 媒体：用户实际发送测试图片/语音，按原消息锚点识别，只产不外发草稿；未取得原音或原图如实写明。
4. 熄屏：实时Off＋Awake、控件可读、停止恢复、重启重建；不要只看旧JSON。
5. LAN：主动断开该固定地址、受控重连、重新核对身份；物理拔USB后进程/心跳继续且无USB设备条目。
6. 自动发送：只有当前明确授权才启用；先测不确定事务/冷却/午夜/新收件合并。不要为“测试”向另一个联系人发送。
7. 生活：事件无重叠/瞬移、工作阶段、旅行链、未来修订、离线后观察与日期导出。复盘按闭合窗口、证据和报告唯一性验证。

真实测试保留任务ID/类型、输入摘要与哈希、输出路径/大小/哈希、起止时间、秒数、点数、结果；按类型汇总次数/秒数/点数及每秒点数。模型订阅额度不能折算时记未知、另记token，不写0假装免费。本机无模型检查为0点。记录存私有evidence，不上传聊天/截图证据。

## 状态检查

先使用只读`scripts/inspect_runtime.py`，该脚本不接手机/模型、不改任何状态。然后按问题补最少证据：监听PID命令、生活PID、scrcpy归属；设备状态只在需要时通过授权手机工具核验。active要求新鲜心跳、send_enabled、无停机/暂停/未确认发送。落盘记录不是进程存活的充分证据。

现有维护脚本仅对明确允许继续的服务调用原启动/主动队列入口。停止标志、stopped状态、用户暂停、sending/uncertain皆不可由普通巡检解除。不要新增高频Codex轮询来代替本地时钟。

| 症状 | 首先核对 | 允许的下一步 |
| --- | --- | --- |
| 无回复 | 新鲜心跳、待处理事务、手机前台/锁屏、模型阶段 | 修对应链路，不删游标重发 |
| 无主动 | 真实时间、机会、冷却、未回应、忙碌/睡觉 | 条件不符是正常，不凑次数 |
| LAN消失 | 同网、固定IP、TCP监听、硬件身份 | 受控重连；重启后必要时USB初始化 |
| 亮屏/Asleep | scrcpy存活、供电、面板与系统、锁屏 | 无锁才显式唤醒，复核身份后熄屏 |
| 其他应用在前台 | 是人工切换还是已知恢复阶段 | 不盲目抢回或猜坐标 |
| 进程启动“挂住” | Windows输出PIPE是否被子进程继承 | 日志文件/TemporaryFile，核对真实PID |
| 两个python PID | venv启动器与实际子进程关系 | 不误杀正常解释器 |
| 模型失败 | 精确model/list、effort、登录/额度、最终JSON | 已配置fallback，均失败保留任务 |
| 发送结果未知 | pending及分段状态、实际气泡 | 停发核对，不再点击 |

## 变更与回退

保持既有服务active时，归档/写文档不应重启它。需要迁移运行组件才正常停止并确认已退出；记住本次创建的停止标志，恢复前核对归属。源文件/配置快照与运行队列分开，不能用旧state覆盖新消息。

LAN回USB：先停机，接原手机核对硬件，只删除连接地址覆盖字段，保留硬件序列号及后来配置；必要时通过已核对LAN目标执行ADB的usb模式。恢复后重新验收联系人、面板及进程。不要reset手机、注销微信、删除聊天。

## 公开归档

新建独立干净Git仓库，白名单选择代码/模板/说明。排除实际config、原始聊天、媒体原件/截图/音频、SQLite及备份、凭据、运行/审计日志、私人角色档案、家人/公司精确地址、设备/联系人标识和真实局域网地址。`.gitignore`不是清理已提交历史的工具，首次提交前就验证暂存清单与内容。

公开模板默认停发，地址使用文档示例地址；真实部署映射仅本机保留。模型/第三方工具从原源安装，个人skill资料不自动转存。源码快照写清外部私有输入和未测试能力，不把通用说明包装成一键可运行承诺。

提交后读回仓库visibility、默认分支、远端SHA和文件树，不能只以push成功为结论；再核对原角色仍active。发布PR时才附PR，不为归档额外创建PR或子任务。
