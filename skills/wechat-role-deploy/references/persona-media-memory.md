# 人格、媒体与连续记忆

## 历史事实、解释与生活模拟分层

仅处理用户有权提供的导出资料；本skill不负责破解加密库或绕过账号授权。历史微信/QQ保留原始平台、会话、消息ID/元素ID、发送方、时间及媒体关联；跨平台人物映射需证据或用户确认，不能凭昵称合并。

优先提取有日期的工作/作息/出差/情绪表达事实，保留矛盾和有效期。来源部署用较新微信作为风格、早期QQ补充记忆，这是该案例选择，不是对所有人通用。公司地址等由用户确认后存私有资料，家庭/第三人的精确地址不进入公开仓库或无关模型上下文。缺失排班、实际旅行频率记未知；不能把模拟参数“证实”为真人现实。

运行人格规则应包含：AI身份知情、与历史真人区别、角色内人格/独立生活/记忆一致性优先、不是讨好助手；可选择跨时空设定，使互动支持与练习成立但不承诺线下见面。此设定不授权冒充真人联系第三人。

最快实现是角色规则＋检索＋持久模拟，不宣称做过权重微调。训练权重、声音克隆或新托管服务需要独立明确范围，不能由“固化skill”自动推出。

## 双账本与连续生活

- 原史料只读，不把AI生成或虚构事件写回真人档案。
- 客观模拟事件：带时区开始/结束、事件ID、地点/交通、工作任务及阶段、前因、依据、记录时刻和版本。滚动七天、出差包含出发/交通/住宿/任务/返程；冲突地点或重叠活动应阻止。
- 实际AI对话：收件观察、生成草稿、发送前状态、确认发送分别记录；保留输入增量、媒体ID和关联事件。草稿不是说过的话。
- 虚构事件先由脚本落盘、再进入模型上下文；模型不能临时声称尚未记录的工作成果或约定。
- 已发生事件不可覆写；只修订未来并保留理由与旧版。停机可补记已排计划的边界，标注离线后观察；没有先前计划的空白不可倒填人生。
- 每日导出“客观事件”“对话记忆”“运行轨迹”；模型只取当前事件、未结事项及必要历史，不每轮全库输入。

## 历史图片、表情、音频保留

原件独立归档，文件名用稳定ID/哈希，保存SHA256、大小、来源消息/元素、变体与缺失原因。原件与派生缩略图、帧图、WAV、转写、标注分开；转换不覆盖原音。表情一张图可能在多条消息中复用，消息关联是多对多，不能按同名文件或邻近文字猜归属。

图片/表情只有真实看过才填写内容标签。GIF单帧不能说明完整动画。媒体习惯按真实对话中发送方/时间段/上下文统计，区分不完整导出导致的缺失；不为凑频率自动插图。WAV解码需核对原编码、采样率、声道、时长，并记录派生链；本仓库不包含原音或第三方解码器。

检索候选含媒体ID、真实内容、语境、原话来源、使用间隔/最近已发。音频历史仅供同意范围内回忆或转写，不据此冒充新录音。实际外发媒体必须独立实现锚点、预览、单次发送与确认；来源部署`outgoing_media_enabled=false`，索引存在不等于外发完成。

## 新收件多模态

手机相册是设备所有者资料，不是角色训练库。仅对绑定会话新收件建立唯一前缀锚点：正文/方向/发送方/类型一起校验，重复或离开可确认范围时停止。

- 图片：打开该条的查看器取得画面送模型，记录`viewer_capture`，不能声称原始图片已下载。
- 表情：捕获该气泡单帧，明确`bubble_frame`限制，不碰可能直接发送的表情面板。
- 语音：优先微信“转文字”；文字不在树中时读取对应转写区域画面。转写失败记未知，不把旁边聊天当语音。未拿到原音不能推断声音、语气或声纹。
- 保存来源锚点、文件哈希、采集时间、识别结果/不确定点；媒体随角色生活/上下文生成回复，按日期写实际对话记忆。

## 参考源码的私有输入契约

公开快照故意不带以下数据。重新部署必须从自己的授权材料建立、调整路径和内部ID；不能复制本案例事实位置当作另一人证据。

| 输入 | 消费者/要求 |
| --- | --- |
| `persona_profile.md` | 模型角色规则，可从通用模板建立 |
| `persona_root/scripts/life.py`及`evidence.py` | 旧档案/天气适配器；快照包含实现参考，需匹配自己的索引 |
| persona `data/world.json`、`cards.json` | 城市/天气参数与审阅卡片；不包含账号凭据 |
| 平台`index.sqlite` | 微信messages/media_links/assets、QQ messages/elements/media_links/assets；只读。精确查询见适配器，不虚构schema |
| `persona_review/<版本>/life-evidence.json` | facts包含id/summary/status/truth_layer/有效期/limits/evidence/context；主题ID与适配器同步 |
| `data/user-facts.private.json` | 用户确认工作资料的workplace字段，去除不必要家庭地址 |
| `data/coaching-patterns.json` | 历史冲突抽取的pattern/source_ids，私人原话不公开；没有资料就关闭相关情境 |
| `data/media/catalog.json` | 原件哈希与消息映射，不能仅填名称；格式见media_catalog.py |

外部人格skill、狗头军师及Kenny方法库不在仓库中；有授权且安装时才使用，缺失应明示，不虚构其观点或全文转存。
