这是一个基于 **Windows 电脑＋安卓备用机＋微信** 的 AI 角色部署方案。你在熟悉的微信里聊天，电脑负责角色记忆、生活模拟和模型调用，备用机负责收发消息。

仓库提供简体中文说明、可供 Codex 使用的部署技能（skill）、配置模板和脱敏参考源码。**它不是下载后就能直接聊天的一键软件**，首次使用仍需准备自己的角色资料，并完成设备适配与验证。

## 用来做什么？

### 1. 与一个有连续生活的角色日常交流

角色不只是每次收到消息才临时编一段回答。它可以有自己的工作、休息、兴趣和日程，记住你们聊过的话，并依据当下的生活情境作出回应。

例如，角色昨天说今天要完成一项工作，那么今天的进度、忙碌时段和晚上的话题应当接得上；不能上一句还在出差，下一句就无缘无故回了家。

这些经历是**明确的虚构生活**，按时间记录；与你的实际对话另行保存，不会混写成现实人物真正发生过的事。

### 2. 练习聊天、社交与关系相处

项目的一个主要出发点，是提供可以反复练习的交流场景：

- 更清楚地表达自己的想法，也能听懂对方真正想说什么。
- 学习共情、给予具体支持和提供情绪价值，而不是一味讨好。
- 练习主动开启话题、自然推进关系，同时尊重边界和彼此的节奏。
- 面对忙碌、失落或意见不同，练习情绪调节与沟通修复。

角色不是只会赞同你的助手。回应应忠于角色设定和已有记忆，而不是为了让你满意随意改变态度。经明确同意，也可加入轻至中度的情境练习；情境要从生活轨迹自然发展，可以暂停，不靠刻意制造争吵来“考你”。

### 3. 从每日对话中找到具体改进方法

可配置每天晚上 **23:30** 在 Codex 中复盘当天的交流，微信里的角色继续保持角色，不突然变成评分老师。

复盘结合对话原文，关注表达、倾听、共情、情绪价值、边界、关系推进、互动节奏和分歧修复等维度，给出具体建议与下一次可尝试的说法。没有足够证据的项目记为“无法评价”，不为了打分而打分。

这是一种练习和反思工具，**不是心理诊断，也不保证现实关系会得到相同反馈**；分数评价的是具体沟通行为，不是一个人的价值。

## 能带来怎样的体验？

下面是来源部署已采用的能力与公开方案的边界；换手机或微信版本仍需重新验证。

| 你想做的事 | 方案如何支持 |
| --- | --- |
| 直接在微信里聊天 | 使用真实安卓备用机上的专用微信，绑定并核对指定会话 |
| 角色记得过去，也有自己的日常 | 检索授权资料，按时间保存模拟事件与实际对话，延续未完成的事情 |
| 不总是由你先开口 | 根据时间、生活情境和冷却规则安排主动机会；未获回应不连续追发，也不凑消息数量 |
| 发图片或语音给角色 | 新收件图片通过画面理解；语音优先使用微信转文字，失败时不猜内容 |
| 保留历史图片、表情和音频 | 记录原件、来源消息和使用语境；原件与转写、缩略图等派生文件分开保存 |
| 不想让备用机一直亮屏、一直插电脑 | 已验证的设备组合可通过局域网连接，并在物理屏幕关闭时运行；系统仍需保持可用 |
| 减少无意义的模型消耗 | 日程推进和常规检查由本地脚本完成，对话、媒体理解和复盘时才调用模型 |

**媒体支持有区别：**保存和检索历史表情，不等于已经能自动发送表情。当前参考方案默认关闭媒体自动外发；查看图片画面不等于下载到原图，语音转写也不等于理解了原音中的语气。

## 适合谁？

适合想研究持续角色记忆、做聊天与社交练习，或希望把已有 AI 角色接入自己备用机的使用者。可以让 Codex 协助部署，但仍需要完成账号登录、设备授权和必要的资料准备。

如果你需要的是无需配置的手机应用、微信官方机器人接口、批量营销工具，或“复制某个真人”的服务，这个仓库并不适合。

## 开始前需要准备什么？

- **一台 Windows 电脑**：运行本地脚本与模型通道；电脑休眠或离线时，不能保证实时回复。
- **一台安卓备用机和自己的微信账号**：由你完成登录和授权。来源部署验证过 Android 12，但不保证所有手机、锁屏方式和微信版本都兼容。
- **可信的局域网与首次连接用的 USB 线**：先完成设备初始化，再验证脱离 USB 后的运行情况。
- **可用的 Codex 与模型权限**：模型可用性、额度和费用以你的账号为准，本项目不附带模型额度。
- **自己的角色设定及有权使用的资料**：仓库不附带私人聊天、人物档案或媒体库；历史检索功能需要你准备对应资料和索引。

具体工具、依赖与版本见[架构与依赖](skills/wechat-role-deploy/references/architecture.md)。当前实现采用角色规则、资料检索和生活模拟，**不要求先训练模型权重，也不声称已经完成模型微调**。

## 怎么开始？

### 第一步：把部署技能交给 Codex

下载仓库，将 [skills/wechat-role-deploy](skills/wechat-role-deploy/SKILL.md) 整个文件夹复制到自己的 Codex 技能目录，保留其中的子目录。如果已有同名技能，先比较，不直接覆盖。

这里的 skill 是给 Codex 阅读的部署操作指南，不是装上就会自动发消息的微信插件。

### 第二步：先准备方案，不开启发送

可以直接对 Codex 说：

> 使用 $wechat-role-deploy，帮我检查电脑和备用安卓机是否具备部署条件，列出缺少的工具与角色资料。在独立目录准备部署，先不要发送微信。

Codex 应按文档完成设备连接、资料适配、角色配置和不外发草稿验证。缺资料时明确提示，不能用虚构内容冒充已有历史。

### 第三步：验证后，再由你确认启用

先核对会话身份、收件识别、草稿内容、局域网与熄屏状态，再进行经你授权的发送验收。**模板默认关闭自动发送**，不能跳过验证直接运行参考源码。

### 已有部署，只想检查状态？

> 使用 $wechat-role-deploy，检查我的既有部署状态，保持角色、模型、频率和收件人不变，不解除暂停，不重发结果不确定的消息。

## 资料与隐私

- 公开仓库不包含私人聊天、媒体原件、人物档案、具体地址、账号凭据或真实运行记录。
- 只使用你有权提供的资料；角色是 AI，不用于冒充真人，也不擅自联系第三人。
- 资料留在本机，不代表对话全程离线：生成回复时，相关文本或图片可能会发送给你配置的模型服务。请先确认可以向该服务提供哪些内容。
- 停止和暂停状态必须保留；发送结果不确定时先核对，不自动重复发送。

## 已验证到什么程度？

来源部署 v3.5.0 曾通过真实 USB 拔线、局域网重连、联系人身份、物理屏幕关闭且系统保持唤醒、进程心跳等检查，对应 61 项定向测试通过。私人验收文件不公开，**这些结果不能替代你自己设备上的验证**。

公开包另有只读状态检查器及 6 项合成数据测试。参考源码保留了案例中的接口和适配假设，需要按自己的资料、路径与设备调整，不是跨机器开箱即用的成品。
